# DEFSA-Arquitectura

Este repositorio contiene la documentación, modelos y entregables del proyecto de arquitectura empresarial desarrollado para la editorial DEFSA, basado en el marco TOGAF 9.1.

## 📁 Estructura del repositorio

- `/informe/`: Documento final del proyecto (PDF).
- `/diagramas e imagenes/`: Diagramas de modelo ER, BPMN, arquitectura en capas, roadmap, y apoyos visuales por fases ADM, biopsicosocial, matriz de riesgos
- `/presentacion/`: Presentación PowerPoint para sustentación final.
- `README.md`: Este archivo.

## 📌 Fases TOGAF documentadas

- Fase Preliminary
- Fase A – Architecture Vision
- Fase B – Business Architecture
- Fase C – Information Systems Architecture
- Fase D – Technology Architecture
- Fase E – Opportunities and Solutions
- Fase F – Migration Planning
- Fase G – Implementation Governance
- Fase H – Architecture Change Management

## 🔗 Herramientas utilizadas

- JIRA (gestión de tareas y roadmap)
- GitHub (repositorio y control de versiones)
- Draw.io y Lucidchart (diagramas)
- Microsoft Word, PowerPoint (documentación)
